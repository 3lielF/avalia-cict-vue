# Avalia CICT 2026 — Mockup interativo em Vue

## Rodar localmente

```bash
npm install
npm run dev
```

Abra a URL exibida pelo Vite.

## Fluxos incluídos

- Avaliador por grande área: Ciências Exatas, Humanas ou Ciências da Vida.
- Dashboard com três tipos: PIBIC, PIBIC-EM e PITCH (PIBITI).
- Toggle Oral / Vídeos.
- Lista de trabalhos filtrada pela grande área.
- Tela de avaliação com critérios, notas, média e comentários.
- Modo vídeo com player simulado em iframe-like area.
- Avaliador PITCH: vê os PITCHs de todas as grandes áreas no mesmo painel.
- Troca de fluxo para facilitar a demonstração do protótipo.

Os dados são mockados e o botão "Salvar avaliação" simula a persistência.
